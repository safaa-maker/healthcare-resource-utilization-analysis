# Clinic Resource Utilization & Patient Analysis

## 📌 Business Overview
This project presents an interactive healthcare operations dashboard built using **Looker Studio** and **Microsoft Excel**. The analysis evaluates clinic resource utilization, financial billing patterns, and patient demographic distribution across 40,000+ patient records to help healthcare administrators optimize staffing, bed capacity, and financial forecasting.

---

## 🛠️ Tools & Technologies Used
* **Microsoft Excel:** Data cleaning, formatting validation, and metric logic verification.
* **Looker Studio:** Data connection, custom calculated metrics (`Avg Length of Stay`), dashboard design, and interactive filtering.

---

## 📊 Key Insights & Metrics
1. **Patient Volume:** Tracked **40,235 total patients** across various medical conditions and admission types.
2. **Financial Overview:** Average billing amount per patient stands at **$25,559.60**, with consistent cost structures observed across Elective, Emergency, and Urgent admission channels.
3. **Operational Efficiency:** Patients maintain an average hospital length of stay of **16 Days**, providing a baseline for capacity planning and bed management.
4. **Insurance Distribution:** Patient coverage is evenly distributed across major payers (Cigna, Medicare, Blue Cross, UnitedHealthcare, and Aetna), each representing ~20% of total volume.

---

## 📈 Dashboard Layout & Features
* **Executive KPI Scorecards:** High-level summary of total patients, average billing, and average length of stay.
* **Medical Condition Breakdown:** Bar chart identifying patient volume trends across primary diagnoses (Arthritis, Diabetes, Cancer, Hypertension, Obesity, Asthma).
* **Admission Cost Comparison:** Categorical analysis of average billing across Elective, Emergency, and Urgent admissions.
* **Interactive Slicers:** Dynamic drop-down filters allowing stakeholders to slice data by **Blood Type** and **Test Results** in real time.
